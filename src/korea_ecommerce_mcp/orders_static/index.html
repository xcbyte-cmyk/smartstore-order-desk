네이버 커머스 API센터에서 발급받은 정보를 입력해 주세요. 입력한 키는 이 PC의 설정 파일에 저장됩니다.

자동 수집 설정

서버가 실행 중인 동안 수집합니다. PC가 꺼져 있거나 절전 상태이면 중단되며, 다시 실행하면 마지막 수집 시점부터 이어집니다.

기간 재수집

선택 기간에 변경된 주문을 다시 가져옵니다. 기존 주문은 중복 추가되지 않고 갱신됩니다.
